# AttendanceWeb Laravel API

Backend PHP Laravel REST API. Frontend folder at `../atd_react` is intentionally empty.

Start with [current API guide](../docs/API-CURRENT.md), [architecture](../docs/03-architecture.md), [API contract](../docs/15-api-contract.md), and [worklog](../docs/worklog.md). The root docs directory is the only maintained specification.

Use the root PowerShell scripts to call the portable PHP/Composer/MySQL runtime. Local .env files contain development credentials and must stay outside Git. No legacy data is imported.
